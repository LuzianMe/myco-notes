# Reviews

Reviews of the notes themselves (method section 21): each file is named review, a date and `.md`, and lists numbered proposals with ready-to-apply fixes, and the owner answers per number. An answered review stays here as the record of what was decided, so a declined fix is not proposed again. Plans and decisions about the project live in `plans/`, not here.
