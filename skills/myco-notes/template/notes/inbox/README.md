# Inbox: quick notes

Thoughts, ideas and things to remember, saved as they come (typed or dictated), one file per month: `YYYY-MM.md`, oldest entry first. Method: `{{DOCS_DIR}}/METHODOLOGY.md` section 19.1.

```
## YYYY-MM-DD HH:MM <short title>
<the note, in the owner's words, lightly cleaned up>
Tags: <a few words> · Related: `<existing-note>.md`
```

- Save one entry per note with `{{TOOLS_DIR}}/capture "the note"` (add `--commit` to commit it). Do not ask questions, verify or change other notes while capturing.
- Sorting is a separate step, when the owner asks: move an entry's content into the note where it belongs, then mark the entry `→ moved to <note>.md (YYYY-MM-DD)` instead of deleting it.
