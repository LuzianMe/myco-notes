# Answer a question from the notes

*Part of the Myco Notes skill: read `SKILL.md` (the folder above) first for `<KIT>`, `<notes>`, `<tools>` and the guard rails, which always apply.*

**When:** The owner asks something the notes can answer.

Run `<tools>/index` (every note with its one-line summary), or `<tools>/search WORDS` when the notes are too many to scan (ranked, with each note's summary and matching lines; `"a phrase"` for exact words), and open the notes it points to, instead of reading files one by one; check the live system when the question is about current state and the notes may be stale. Answer with the file names you used and say what is not verified. If the answer took several notes, a live check or research, end with ONE line offering to keep it and saying where ("Keep this as a how-to in `runbook.md`?"; a decision record, an entity-note section, or a new note when nothing fits; method 5, item 15). On a yes, write it with the steps of `capture.md` (sources named, sync-log kind `answer`), then commit. Do not offer it for one-line look-ups; save without asking only if the working agreement says answers are always kept.
